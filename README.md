Một trang web đơn giản chỉ xoay quanh 3 thành phần:

**HTML (index.html)**: Bộ khung xương (chứa câu chữ, thẻ ảnh, nút bấm, thẻ phát nhạc).

**CSS**: Da thịt và quần áo (căn chỉnh chữ ra giữa, chọn màu nền, chỉnh ảnh bo tròn).

**JavaScript**: Phản xạ tương tác (khi người dùng bấm chuột vào nút "Mở thiệp" thì phát nhạc và ẩn chiếc phong bì đi).
